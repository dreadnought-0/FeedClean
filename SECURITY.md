# Security policy

## Reporting a vulnerability

Please report security issues **privately** using GitHub's "Report a vulnerability" feature (a private security
advisory) on this repository's Security tab. Do not open a public issue for a vulnerability.

Helpful details: affected version or commit, what an attacker could do, and steps to reproduce. Do not include
real personal data, TikTok account details, or raw screen captures.

## Scope

In scope: data leaks from the app, anything that could cause the app to act without the user's tap, unexpected
network access, unsafe handling of imported files or selector override files, or weaknesses in the export/import
code.

Out of scope: vulnerabilities in TikTok or Android themselves, and reports that rely on a device that is already
rooted or compromised.

## Supported versions

Only the latest release is supported. Security fixes land on the main branch and ship in the next release.
